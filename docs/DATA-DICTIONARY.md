# 产线停机裁决与效率重算数据定义

计划分钟=运行分钟+有效停机分钟。班次总分钟=计划分钟+休息并集分钟。总产=良品+废品。起止时间使用含偏移的ISO格式，班次最长24小时。区间采用[start,end)，超出班次的停机裁剪，重叠休息只扣一次。total与good为整数件，ideal_seconds为每件理想秒数。零计划、零运行、零产量分别给出状态，不以任意分母补零。

班次按休息与停机所有端点切片，先扣休息并集，再按安全、故障、换型优先级分配停机。OEE使用未舍入的三因子计算，并保留超产异常。

原始行号对应 CSV 解析器的物理末行。UTF-8 BOM 与 GB18030 均支持，坏行进入隔离区，结构性错误返回422。空文件、仅表头和全空记录分别返回不同原因码。金额与用量使用 Decimal，对外以字符串返回。编码和编号按字符串保留。

run_id 由输入摘要、参数和规则版本生成；revision 为人工复核版本。证据 CSV 含运行号、版本状态、修订、来源行、原因码、原始字段及最终结论。

## 版本谱系
同一组班次（产线+班次日期，按 Jaccard 重合度≥0.5 归并）的多次提交构成版本谱系，每组同时只有一个现用版本，登记状态如下：

| 状态 | 含义 | 可复核 | 可切换 |
|---|---|---|---|
| 现用 | 工作台默认展示、证据下载与后续修订的基线 | 是 | — |
| 待生效 | 新提交的修订，等待核对与显式切换 | 是 | 复核通过后可 |
| 已撤回 | 被更晚的待生效版本取代 | 否 | 否 |
| 已替换 | 曾经现用，已由后续版本切换取代 | 否（只读） | 否 |

运行正文按 run_id 保存且永不改写；版本状态单独存放，切换只改状态与生效时间。已替换/已撤回版本的 sha256、逐行原始记录与 evidence.csv 保持提交时的内容。
